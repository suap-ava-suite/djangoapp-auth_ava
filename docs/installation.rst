Instalação
==========

O ``django-auth-ava`` pode ser instalado via ``pip`` ou ``uv``:

Com pip
-------

.. code-block:: bash

   pip install auth-ava

Com uv
------

.. code-block:: bash

   uv add django-auth-ava

Requisitos
----------

* Python >= 3.14
* Django >= 6.0, < 7.0
* django-suap-auth >= 1.0.1
* django-simple-history >= 3.7.0
