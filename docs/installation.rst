Instalação
==========

O ``django-auth-ava`` pode ser instalado via ``pip`` ou ``uv``:

Com pip
-------

.. code-block:: bash

   pip install django-auth-ava

Com uv
------

.. code-block:: bash

   uv add django-auth-ava

Requisitos
----------

* Python >= 3.12
* Django >= 5.2, < 7.0
* django-suap-auth >= 1.2.0
* django-simple-history >= 3.7.0
